The passphrase you set when you deployed the backend. It stops strangers from using your API credit — it isn't saved anywhere, you type it each time.

Works best with real text (a digital textbook PDF). A scanned/photographed page will fall back to OCR automatically, but OCR makes mistakes — you'll get a chance to fix them in the next step.
